# Serenity Lux Floral

Marketing site for [@serenityluxfloral](https://www.instagram.com/serenityluxfloral/), an Ajax florist serving Toronto and the GTA. Imported flowers from Ecuador and Colombia, 5–7 days’ notice, and a 50% non-refundable deposit.

```bash
npm install
npm run dev -- --port 4329
```
